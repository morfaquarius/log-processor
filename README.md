# Log Processor

Проект на Go для обработки CSV-файлов веб-логов и генерации статистики.

## О проекте

Этот проект читает лог-файл `testdata/logs.csv`, парсит записи, обрабатывает их в параллельных воркерах и выводит:

- общий отчёт по всем запросам;
- статистику по ошибкам;
- топ IP-адресов по количеству запросов.

Проект демонстрирует простую и устойчивую архитектуру обработки потоковых данных в Go.

## Особенности

- чтение CSV-файла по строкам без блокировок;
- многопоточная нормализация URL;
- подсчёт ошибок при статусах `>= 400`;
- расчёт среднего времени ответа;
- дублирование потока для параллельных вычислений.

## Требования

- Go 1.25 или выше
- Windows / macOS / Linux

## Установка

Откройте терминал в корне проекта `log-processor`:

```bash
cd path/to/log-processor
```

Если требуется установить зависимости или синхронизировать модули:

```bash
go mod tidy
```

## Запуск

### Быстрый запуск


### Сборка и запуск бинарника


### Тестирование


```text
log-processor/
┌── main.go             # точка входа в программу
├── processor.go        # логика обработки логов (readLogs, processLogs, filterLogs, calculateStats)
├── testdata/
│   └── logs.csv        # тестовый файл с логами (минимум 10-15 записей)
├── go.mod              # файл модуля Go
├── README.md           # инструкция по запуску с примерами команд
└── processor_test.go   # базовые тесты
```

## Как работает

1. `main.go` запускает конвейер обработки.
2. `readLogs()` считывает CSV и передаёт записи через канал.
3. `processLogs()` запускает пул воркеров, нормализуя URL и пропуская данные дальше.
4. `tee()` дублирует поток логов для параллельного подсчёта общей статистики и ошибок.
5. `calculateStats()` собирает метрики по каждому потоку.
6. `printTopIPs()` выводит наиболее активные IP.

## Примечания

- Строки с некорректным форматом логов логируются и пропускаются.
- Ошибки считаются для HTTP-статусов `>= 400`.
- Порог `filterLogs()` можно легко изменить для других уровней.
